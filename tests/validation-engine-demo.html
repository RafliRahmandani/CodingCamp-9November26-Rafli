📋 ValidationEngine Module Demo

Sistem Validasi Marketplace Indonesia dengan Pesan Error Bahasa Indonesia

🎯 Apa itu ValidationEngine?

ValidationEngine adalah modul JavaScript yang menyediakan validasi komprehensif untuk semua 14 field formulir customer management marketplace. Modul ini menggunakan pattern IIFE untuk enkapsulasi, menyediakan pesan error dalam bahasa Indonesia, dan dapat dengan mudah diintegrasikan ke dalam aplikasi.

📚 Public API Methods
ValidationEngine.validate(fieldName, value, customRules)
Validasi single field dengan semua rules yang tersedia. Returns: {valid: boolean, errors: string[]}
ValidationEngine.validateField(fieldName, value)
Simplified version untuk mendapatkan error message pertama saja. Returns: {valid: boolean, message: string}
ValidationEngine.validateForm(formData)
Validasi keseluruhan form dengan 14 field sekaligus. Returns: {valid: boolean, errors: Object}
ValidationEngine.getFieldRules(fieldName)
Dapatkan validation rules untuk field tertentu. Berguna untuk form generation.
ValidationEngine.getAllRules()
Dapatkan semua validation rules untuk 14 field.

🧪 Contoh Validasi

✅ Validasi Valid
namaBarang: "Smartphone Samsung"
Valid: ✓ Field diterima
❌ Validasi Invalid - Required
namaBarang: "" (kosong)
Error: Nama Barang harus diisi
✅ Validasi Valid - Optional
varianBarang: "" (kosong)
Valid: ✓ Field opsional boleh kosong
❌ Validasi Invalid - Length
namaBarang: "a".repeat(101)
Error: Nama Barang maksimal 100 karakter
❌ Validasi Invalid - Numeric
hargaBarang: "abc"
Error: Harga Barang harus berupa angka
❌ Validasi Invalid - Phone
noTelp: "123456789" (9 digit)
Error: No Telp harus 10-13 digit angka
✅ Validasi Valid - Phone Format
noTelp: "+62-812-3456-7890"
Valid: ✓ Format diterima (12 digit)
❌ Validasi Invalid - Min Value
kuantitas: 0 (min 1)
Error: Kuantitas minimal 1

🚀 Features

  • ✅ IIFE Module Pattern untuk enkapsulasi
  • ✅ Validasi lengkap 14 form field marketplace
  • ✅ Pesan error dalam bahasa Indonesia
  • ✅ Return format {valid, message/errors}
  • ✅ Support validasi field tunggal dan form keseluruhan
  • ✅ Tidak ada external dependency
  • ✅ Siap untuk integrasi ke form transaction
